# IRAQ B7R — تطبيق أندرويد أصلي (Kotlin)

تطبيق كامل مبني من الصفر بلغة Kotlin (مو WebView)، فيه نفس مزايا التطبيق القديم (عربات، أرشيف، إعدادات) + **ويدجت عائم** يبين أقرب عربة تخلص فوق أي تطبيق ثاني.

## كيف تفتحه وتبنيه (APK)

1. حمّل ونصّب **Android Studio** (مجاني): https://developer.android.com/studio
2. افتح Android Studio → File → Open → اختر مجلد `IraqB7rApp` (هذا المجلد نفسه).
3. خلي Android Studio يسوي "Gradle Sync" أول مرة (يحتاج إنترنت، يحمّل المكتبات تلقائياً — قد تاخذ بضع دقائق).
4. من القائمة فوق: Build → Build Bundle(s) / APK(s) → Build APK(s).
5. لما يخلص البناء، بيطلعلك إشعار "APK(s) generated successfully" مع رابط "locate" يوديك لمكان ملف الـ APK.
6. انقل ملف الـ APK لجوالك ونصّبه (لازم تفعّل "تثبيت من مصادر غير معروفة" بإعدادات جوالك أول مرة).

## شلون تشغل الويدجت العائم بعد التنصيب

1. افتح التطبيق → تبويب **الإعدادات**.
2. اضغط **"تفعيل صلاحية العرض فوق التطبيقات"** — بيوديك لصفحة إعدادات أندرويد، فعّلها يدوياً (خطوة أمان إجبارية من أندرويد نفسه، ما تكدر تتخطاها برمجياً).
3. ارجع للتطبيق واضغط **"تشغيل الويدجت العائم"**.
4. بيطلع ويدجت صغير فوق الشاشة يبين اسم أقرب تحالف والوقت المتبقي، وتكدر تسحبه لأي مكان بالشاشة.
5. بيضل شغال حتى لو طلعت من التطبيق أو فتحت تطبيقات ثانية — لأنه خدمة Foreground Service مستقلة.

## ملاحظات مهمة

- **البيانات منفصلة تماماً** عن تطبيقك القديم (ملف الـ HTML عبر WebIntoApp) — هذا تطبيق جديد من الصفر، لازم تضيف عرباتك فيه من جديد.
- بعض الأجهزة (Xiaomi / Huawei / Oppo وغيرها) عندها إعدادات توفير طاقة عدوانية تسكر الخدمات بالخلفية تلقائياً. إذا لاحظت الويدجت يوقف بعد فترة، روح لإعدادات الجهاز → البطارية → التطبيقات → IRAQ B7R → فعّل "بدون قيود" أو "Autostart".
- الإشعار الثابت الصغير (يقول "الويدجت العائم يعمل الآن") إجباري من أندرويد لأي Foreground Service — ما تكدر تخفيه بالكامل، بس خليته بأقل أولوية ممكنة (ما يرن ولا يهتز).
- التطبيق يطلب صلاحية الإشعارات (لتنبيهك قبل دقيقة من انتهاء عربة، وعند اكتمالها) — اقبلها لأفضل تجربة.

## هيكلة المشروع (لو حبيت تعدل بنفسك لاحقاً)

- `CartItem.kt` — شكل بيانات العربة الواحدة.
- `DataStore.kt` — التخزين المحلي (SharedPreferences)، نفس مصدر البيانات يستخدمه التطبيق والويدجت العائم سوا.
- `CartEngine.kt` — منطق العد التنازلي المشترك (يحدد أقرب عربة، ينقل المنتهية للأرشيف، يرسل التنبيهات).
- `MainActivity.kt` — الشاشة الرئيسية بتبويباتها الثلاث.
- `OverlayService.kt` — خدمة الويدجت العائم نفسها.
- `BootReceiver.kt` — يعيد تشغيل الويدجت تلقائياً بعد إعادة تشغيل الجهاز (إذا كان مفعّل).
